Language-model agents that answer questions about tables usually write and run code, which is hard to audit and unsafe on untrusted files. We describe a single-agent system for tabular analysis in which a small local model (qwen3:4b-instruct, 4 GB GPU) only proposes a plan, a graph of typed tasks that can be revised during a run, while eight registered deterministic tools compute every number. Each result is stored as an evidence record, and a number appears in a report only if it matches a record. We evaluate on 20 questions about a retail sales table against an oracle computed separately from the raw file. With replanning enabled the agent passes \MainQ{} of \MainN{} questions; with replanning disabled it passes \NoRepQ{} of \NoRepN{} using \NoRepCalls{} model calls instead of \MainCalls{}. In the runs with replanning, the model kept adding analyses after a correct first result, and because the answer is read from the last executed task, the added analyses displaced correct answers. Three smaller local models pass between 1 and 8 of the 20 questions. The system was changed after an earlier run on the same questions, so the results are not a held-out measurement, and the benchmark is small and covers a single table.
