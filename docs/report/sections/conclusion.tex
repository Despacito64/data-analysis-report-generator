\section{Conclusion}
We built a single-agent system in which a small local model plans and fixed tools compute, with every reported number tied to an evidence record. On 20 questions about one table it passed \MainQ{} with replanning enabled and \NoRepQ{} with replanning disabled, the second using half the model calls. The difference comes from replanning calls that added analyses after a correct first result, which the answer rule then took for the answer. Three smaller local models passed between 1 and 8 questions. The results are not a held-out measurement, because the system was changed after an earlier run on the same questions.

The next steps are to read the answer from the task the plan designates and not from the last one to run, to make \texttt{rank} work on grouped output and to restrict trends to the period asked about, to add longer dependent questions on which replanning can be tested, and to evaluate on questions the system has not seen, including an external benchmark. The claim checker and the narration step should also be measured directly. Until then the results describe one table, one model and twenty questions.
